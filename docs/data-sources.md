# データソース

## 出典

出入国在留管理庁「在留外国人統計」（e-Stat）。各年末（12月末）の国籍・地域別 在留資格（在留目的）別の表を読む。
statInfId と形式は `src/lib/data/sources.ts`。

- 2012年末以降: 「国籍・地域別 在留資格（在留目的）別 在留外国人」。在留外国人は中長期在留者と特別永住者。
- 2006–2011年末: 旧「登録外国人統計」の「国籍（出身地）別 在留資格（在留目的）別 外国人登録者」。
  外国人登録者から「短期滞在」「未取得者」「一時庇護」「その他」を除いた数を、在留外国人の参考値とする。
  出入国在留管理庁の推移表（2011年以前は「中長期在留者に該当し得る在留資格」と特別永住者の合計で、在留期間が3月以下の人を含む）と同じ数え方で、総数が一致する。
- 2005年以前は表が画像の PDF しかないため扱わない。
- 2020・2021年末は Excel がなく、閲覧用（fileKind 4）のファイルを取る。
- 6月末の値は使わない（年末だけで揃える）。

## 表の形

- 2022年6月末まで: 横持ち。見出しは2–3行で、年によって行・列がずれる。列ごとに見出しのセルを上から連結した名前で在留資格を引く。
  - 2019年末以降は国籍・地域名が1列目、総数が2列目。それ以前は1列目が州、2列目が国籍・地域。
  - 「特定活動計」「日本人の配偶者等計」のような合計の列を使い、内訳の列は使わない。
- 2022年末以降: 縦持ち（時点・州・国籍・地域・在留資格・[在留目的]・人数）。
  - 在留目的の列がある年（2022年末・2023年6月末）は「計」の行だけ。
  - 「…合計」の行は使わず、号の行を足す。「うち…」の行と州の行は使わない（「無国籍」は国籍として扱う）。

## 在留資格の揃え方

- 「技術」と「人文知識・国際業務」は2015年に「技術・人文知識・国際業務」に統合された。それ以前は2つを足す。
- 「投資・経営」は2015年に「経営・管理」に変わった。
- 「高度専門職」「特定技能」「技能実習」は号の別を足す。
- 表に初めて現れる年: 技能実習 2010、高度専門職 2015、介護 2017、特定技能 2019。「就学」は2009年末まで。
- まとまり（`src/lib/data/groups.ts`）は出入国在留管理庁の区分に沿い、「専門的・技術的分野」から「特定技能」を分けて示す。

## 国籍・地域の揃え方

- 「韓国・朝鮮」は2014年末まで1行、2015年末から「韓国」と「朝鮮」に分かれる。
- 台湾は2011年末まで「中国」に含まれる。
- そのため、国籍・地域の推移は2015年末から描き、順位は全年で出す。
- 国名の変更や表記の揺れ（グルジア→ジョージア、マケドニア→北マケドニアなど）は最新の名前に揃える（`scripts/build.ts` の `ALIASES`）。同じ年に揃え先の名前がすでにあれば止める。

## パイプライン

1. `fetch` — Excel を `data/raw/{year}.xls(x)` へ（追跡しない）
2. `normalize` — 表を読み `data/normalized/tables.json` へ
3. `data` — 国籍・地域×年×在留資格の配列 `public/data/status.json` へ（型は `src/lib/data/cube.ts`）
4. `verify` — 次を確かめる
   - 各国籍・地域の在留資格の和が総数に一致する
   - 国籍・地域の和が総数の行に一致する（総数と各在留資格）
   - 2011年末以前は、除く区分を引いた総数が出入国在留管理庁の推移表の値に一致する
   - 2012年末以降は、除く区分の値がない
   - 国籍・地域名が重ならず、年が連続している
